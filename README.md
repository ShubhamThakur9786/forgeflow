# ForgeFlow

ForgeFlow is a production-oriented multi-tenant SaaS platform built with:

- Python
- Django
- Django REST Framework
- React
- PostgreSQL
- Redis
- Celery
- WebSockets
- Razorpay
- Docker

## Project Goals

ForgeFlow is being built as a full-stack learning and portfolio project focused on:

- Backend architecture
- REST API design
- PostgreSQL and SQL
- Authentication and MFA
- RBAC and multi-tenancy
- Caching
- Background processing
- Real-time communication
- Payment integration
- Testing
- Dockerization
- Deployment
- Monitoring
